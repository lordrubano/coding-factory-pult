# Отчёт по шагу IMP-025 — изоляция конфигурации рецензента

Второй шаг Фазы 4. Предмет: проверяемый проект не влияет на судью.

## Что обнаружено до правки

Дыра была измерена чтением кода, а не предположена. Рецензент запускался с
рабочим каталогом в самом проверяемом дереве, и argv не называл источник
настроек вовсе. Следствие: файл настроек, памятка исполнителю и перехватчики,
лежащие в проверяемом дереве, были доступны судье и могли им управлять — автор
кода мог писать рецензенту инструкции тем же коммитом, который тот проверяет.

## Что получили

```
рабочий каталог   создаётся заново во временном каталоге системы; пуст;
                  не внутри цели и не внутри репозитория фабрики;
                  каталог внутри цели -> JUDGE_WORKDIR_INSIDE_TARGET
настройки         runtime/automation/judge_settings/settings.json,
                  названы в argv явно, абсолютным путём;
                  отсутствие -> JUDGE_SETTINGS_UNAVAILABLE,
                  внутри цели -> JUDGE_SETTINGS_INSIDE_TARGET
среда             список разрешённого из тринадцати переменных, объявлен
                  одним местом; посторонняя переменная внутрь не попадает
проектные         выключены пятью ключами запуска и пустым значением
источники         источников настроек; каждый ключ закреплён случаем
артефакт          по-прежнему передаётся через стандартный ввод
```

## Чем доказано

Живая проба арбитра по четырём точкам: каталог, argv, среда с подложенной
посторонней переменной, отказы на настройках внутри цели. Машинные факты:
регрессия 95 из 95; мутации 421 из 421 убиты; датчик секретов чист; сверка
приватной области публикации CF_PUBLISH_OK; набор судьи 24 -> 32 случая;
спецификаций на модуль судьи 30, все убивают.

Две спецификации сняты с основанием: проверка пустоты свежесозданного каталога
недостижима ни одним входом; проверка наличия каталога настроек дублируется
проверкой файла с тем же исходом — свойство закрыто спецификацией по файлу.

## Попутная находка

Файл настроек судьи не попадал в хранилище: правило игнорирования
runtime/automation/* отсекало его молча. На чужой машине судья отказал бы без
очевидной причины. Починено правилом на директорию целиком, без пофайлового
разблокирования — третий случай этого класса за проект.

## Что осталось неизвестным

Ключи запуска сверены с заданием, а не с живым инструментом: сеть и настоящие
вызовы рецензента запрещены. Если инструмент нынешней версии какой-то ключ не
примет, судья откажет — отказом, а не молча; узнаем при первом настоящем вызове
после решения о модели на IMP-032. Значений конфигурации по-прежнему нет:
AD-29 открыт, решение владельца вынесено на IMP-032.

## Что это меняет для владельца

Судья перестал читать проверяемое дерево. Вердикт рецензента, когда тот
заработает, нельзя будет подделать содержимым проверяемого коммита.
